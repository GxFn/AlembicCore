## 对象身份与状态

| 项目 | 含义 |
| --- | --- |
| 产生 | 调用者整理观察/语义机制；canonicalizeObservationPopulationV1与canonicalizeKnowledgeClustersV1核验和规范。 |
| 消费 | Induction/Falsification、独立KnowledgeDispositionReview及StrictProductionAuthority组合验证。 |
| 持久化 | 这些构造器只返回冻结对象；耐久存储由调用者提供。 |
| 身份 | populationId+revision+parentPopulationHash记录版本链，populationHash绑定分母、处置、source revision与完成状态；clusterSetHash另绑定populationHash、机制成员及每观察disposition，不能互换。 |
| 失效 | 新源码、执行集合、观察处置或机制成员变化产生新hash；revision>1必须带parent，但constructor本身不查磁盘证明parent存在。 |

| 状态/阶段 | 含义 |
| --- | --- |
| complete | population完整声明且真实执行守恒，无遗漏/截断/continuation/error。 |
| unknown | 保留分母与缺口；不得转述为无模式或完成。 |
| clustered | 每观察的一条disposition可引用多个cluster。 |
| unresolved | 未成簇需reason/owner/resumePoint。 |
| discarded | 需独立pass review精确绑定此population和discard提案。 |
