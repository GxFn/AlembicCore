## 对象身份与状态

| 项目 | 含义 |
| --- | --- |
| 产生 | 注入evidenceStore与host adapter的V5 gateway形成load/execution/signature；consumeMain...验证后形成KnowledgeDispositionReview。 |
| 消费 | 预先持有expected trust policy和当前semantic request的消费端；相应cluster-discard/zero-hypothesis/falsification/producer处置合同。 |
| 持久化 | attestation设计为可序列化跨进程验证；gateway/consumer本身不承担外层文件保存。 |
| 身份 | attestation签名/内容hash绑定精确request、完整harvest groups、load receipts与host execution；消费端再比对expected request，review另有reviewReceiptId/receiptHash与fixpoint/proposal绑定。 |
| 失效 | request、证据root/group、execution、trust policy或签名字节变化会拒绝；旧合法签名不能授权另一份当前请求。 |

| 状态/阶段 | 含义 |
| --- | --- |
| 已签出 | gateway经过真实adapter接口调用和校验后返回；不等于外层已持久保存。 |
| 已验证 | 消费端按expected policy验签/集合；尚需当前request相同。 |
| 已消费 | 返回对应KnowledgeDispositionReview；不是G1/G2或公开发布许可。 |
