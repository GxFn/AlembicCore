## 对象身份与状态

| 项目 | 含义 |
| --- | --- |
| 产生 | SourceGraphIndexer 根据 inventory、解析事实与链接结果构建 generation；ProjectRelations.ensureIndex 显式通过 lifecycle 选择 full/incremental/fresh-noop。 |
| 消费 | SourceGraphQueryService 与 ProjectRelations.query 消费已保存图；evidence/sourceSections 在需要正文时还要读取当前文件并验证引用。 |

| 状态/阶段 | 含义 |
| --- | --- |
| uninitialized | 关系 query 无代际时显式 unavailable 并提示 build，不以空结果冒充确定无关系。 |
