# 删除恢复先按已发生的效果分流

同一个delete reject可以对应不同残留。文件移除、逐个referrer更新、目标/FK事务、兼容清理、审计和同步事件没有共同事务。先沿当前状态选择路径，再决定显式恢复。

V06把真实文件/SQLite证据与注入审计/事件边界分开；事件发出不代表向量已刷盘。
